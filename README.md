## 🚨 Критичные известные проблемы

Перед установкой учитывайте две открытые проблемы:

- **Лишняя системная раскладка U.S./ABC.** macOS может блокировать её удаление
  кнопкой `−`, даже когда обе cross-раскладки уже добавлены. В переключателе
  остаётся третий источник ввода. Обходной путь через настройки `HIToolbox.plist`
  требует проверки и резервной копии — подробности в [issue #1](https://github.com/bijibox/ru-en-cross-macos-keyboard-layout/issues/1).
- **Плохо видимые значки возле курсора.** В индикаторе языка macOS Sonoma и новее
  значки cross-раскладок могут терять контраст или почти исчезать на синей плашке.
  Проверка иконок и способ отключения индикатора описаны в [issue #2](https://github.com/bijibox/ru-en-cross-macos-keyboard-layout/issues/2).

Обе проблемы открыты; применимость обходных путей к вашей версии macOS
нужно проверить. Подтверждённые результаты будут добавлены в документацию.

## ↔️ Английское слово посреди русского предложения? Легко.

Имя переменной, команда в терминале, короткое `git status` или просто `;` —
ради них не обязательно переключать источник ввода. В `ru-en-cross` клавиша
<kbd>Option</kbd> временно включает второй язык:

```text
    РУССКИЙ                        ENGLISH
       │                              │
       ├── зажать ⌥ ──→ English       ├── hold ⌥ ──→ Русский
       └── отпустить ─→ Русский       └── release ──→ English
```

В основе — привычные системные **U.S.** и **Russian – PC**.
Обычный ввод сохраняется, а слой `Option` отдан под второй язык вместо
типографских символов. Сочетания с `Command` используют латинский QWERTY.

## 🚀 Установка

Нужны **macOS** и **Python 3.9+**. Дополнительных Python-пакетов нет —
достаточно стандартной библиотеки.

```bash
git clone https://github.com/bijibox/ru-en-cross-macos-keyboard-layout.git
cd ru-en-cross-macos-keyboard-layout
python3 ru_en_cross.py install
```

1. Выйдите из учётной записи macOS и войдите снова.
2. Откройте **Системные настройки → Клавиатура → Ввод текста → Изменить**.
3. Добавьте обе раскладки:

   | Раскладка | Обычный ввод | С зажатой ⌥ Option |
   | :--- | :--- | :--- |
   | **Russian – PC cross U.S.** | Русский | Английский |
   | **U.S. cross Russian – PC** | Английский | Русский |

Бандл устанавливается в `~/Library/Keyboard Layouts/ru-en-cross.bundle`.
При ошибке генерации или записи предыдущая установка сохраняется.

<details>
<summary><strong>Уже установлена старая версия?</strong></summary>

Сначала переключитесь на системную раскладку и удалите старые cross-источники
из списка ввода. Обновите проект и переустановите бандл:

```bash
git pull
python3 ru_en_cross.py install
```

Выйдите из учётной записи и войдите снова, затем добавьте обе раскладки
заново. В старых версиях использовались другие внутренние идентификаторы,
а macOS кэширует установленные раскладки и их значки.

</details>

## 🎛️ Как работают клавиши

| Клавиши | Поведение в обеих раскладках |
| :--- | :--- |
| Без модификаторов | Базовая U.S. или Russian – PC |
| <kbd>⌥ Option</kbd> | Второй язык, обычный регистр |
| <kbd>⌥ Option</kbd> + <kbd>⇧ Shift</kbd> | Второй язык, верхний регистр и знаки с Shift |
| <kbd>⌘ Command</kbd> | Латинский QWERTY для сочетаний клавиш |
| <kbd>⌘ Command</kbd> + <kbd>⇧ Shift</kbd> | Латинский QWERTY с Shift |
| <kbd>⌃ Control</kbd> | Системный управляющий слой U.S.; приоритет над остальными модификаторами |

<details>
<summary><strong>Caps Lock, цифровой блок, Ё и другие подробности</strong></summary>

- **Caps Lock** не меняет регистр в `Option`-слое. Для верхнего регистра
  используйте `Option` + `Shift`.
- **Цифровой ряд** тоже переключается: `Option` + `1` даёт `1`,
  а `Option` + `Shift` + `1` — `!` в обеих раскладках.
- **Command** сохраняет латинский слой даже с зажатым `Option` или Caps Lock.
- **Control** передаёт управляющие символы U.S.: например,
  `Control` + `C` — U+0003, `Control` + `[` — Escape.
- **Цифровой блок** сохраняет базовую раскладку, включая десятичный разделитель.
- **Return, Tab, Backspace, Delete и стрелки** сохраняют служебные коды.
- **Левые и правые модификаторы** Option, Shift и Control работают одинаково.
- **ANSI, ISO и JIS** поддерживаются. На ANSI клавиша `ё` находится слева от `1`,
  на ISO — рядом с левым Shift. Верхний регистр даёт кириллическую `Ё`;
  ошибочная латинская `Ë` системной Russian – PC на ANSI исправлена.

Раскладка определяет символы, которые получает приложение. Сочетания,
назначенные в приложении или системе, например `Option` + Space,
могут сработать как команды до ввода текста.

</details>

## 🌓 Узнаваемые значки

**US** и **РУ**, жирные буквы и маленькая стрелка `↔`, чтобы отличать
cross-раскладки от штатных. У `РУ` — прозрачная середина и контурная рамка.
Обе иконки занимают весь холст **16 × 16**, имеют Retina-варианты
и адаптируются к теме и выделению в меню.

## 🛠️ Сборка и тесты

| Команда | Что делает |
| :--- | :--- |
| `make build` | Собирает `build/ru-en-cross.bundle` |
| `make install` | Собирает и устанавливает обе раскладки |
| `make icons` | Пересоздаёт ICNS, PNG и обзор значков |
| `make test` | Запускает тесты на Python |
| `make test-macos` | Проверяет раскладки системным обработчиком macOS |

Сборка воспроизводима: `.keylayout` генерируются из сохранённых таблиц
[`data/system_layouts.json`](data/system_layouts.json), без зависимости
от старого бандла или содержимого `build/`.
[Происхождение таблиц и их обновление →](data/README.md)

**Обычные тесты** проверяют символы, регистр, все 256 комбинаций модификаторов,
служебные клавиши, структуру бандла и сохранение предыдущей установки при ошибках.
Сборка и эти тесты работают также вне macOS.

**Системная проверка** на macOS сравнивает **3 407 872 результата ввода**
через `UCKeyTranslate`, а также имена и языки раскладок. Она создаёт временный
бандл, регистрирует его для компиляции и удаляет после проверки.
Тестовые источники не включаются и не выбираются.

<details>
<summary><strong>Сборка без make и выбор папки</strong></summary>

```bash
python3 ru_en_cross.py build
python3 ru_en_cross.py build /path/to/output
python3 ru_en_cross.py install
python3 -m unittest discover -s tests
```

По умолчанию бандл создаётся в `build/`. Python 3.9+ и его стандартной
библиотеки достаточно для сборки и обычных тестов; установка и системная
проверка предназначены для macOS.

</details>
